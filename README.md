# 📊 PhonePe Transaction Analysis Dashboard

## 📌 Project Overview

This project presents an interactive **PhonePe Transaction Analysis Dashboard** built in **Microsoft Power BI**. The dashboard provides meaningful insights into digital payment transactions, user behavior, insurance statistics, and transaction trends across different states and years.

The objective of this project is to transform raw transaction data into an easy-to-understand analytical dashboard that helps identify payment trends, user growth, and business performance through powerful visualizations.

---

## 🎯 Project Objectives

- Analyze PhonePe transaction performance.
- Track transaction amount and transaction count.
- Analyze registered users and app opens.
- Compare state-wise digital payment trends.
- Identify yearly and quarterly growth.
- Build an interactive dashboard for business decision-making.
